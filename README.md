# 📚 BOOKY - Cadastro de Estudantes
 
O **BOOKY** é um aplicativo mobile desenvolvido com **React Native** e **Expo**. Ele funciona como um formulário de cadastro simplificado para estudantes, permitindo inserir informações pessoais, acadêmicas e exibir os dados imediatamente na tela após o envio.
 
---
 
## 🚀 Funcionalidades
 
- 📋 **Formulário Completo**
  - Nome
  - Curso
  - Disciplina
  - Descrição pessoal
 
- ✅ **Validação Simples**
  Verifica se todos os campos estão preenchidos antes de exibir os dados.
 
- ⚡ **Exibição Dinâmica**
  Os dados aparecem na tela assim que o botão **"Enviar"** é pressionado.
 
- 🔄 **Feedback de Inicialização**
  Uso do `useEffect` para registrar o início do app no console.
 
- 📱 **Interface Responsiva**
  Uso de `SafeAreaView` e `ScrollView` para adaptação em diferentes dispositivos.
 
---
 
## 🛠️ Tecnologias Utilizadas
 
- React Native

  - `useEffect`
